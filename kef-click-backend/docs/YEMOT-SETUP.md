# חיבור ימות המשיח לכיף Click

## איך זה עובד
1. המשתתף מתקשר למספר של המערכת שלך בימות המשיח.
2. ימות המשיח פונה לשרת שלך (`/api/yemot/call`) ושולח את מספר הטלפון.
3. השרת מזהה את המשתתף, ועונה בטקסט: מה להקריא, ולבקש הקשה של מקש אחד.
4. כשהמשתתף מקיש 1 עד 4, ימות המשיח שולח לשרת `answer=<המקש>`, והשרת עונה "תשובה נכונה" או "תשובה שגויה".
5. אם לא הוקש כלום במשך 60 שניות, ימות המשיח שולח `answer=None`, והשרת פשוט מבקש שוב. כך השיחה נשארת פתוחה לאורך כל המשחק.
6. כשהמשתתף מנתק, ימות המשיח שולח `hangup=yes`, והמשתתף מסומן "לא מחובר".

## הגדרת השלוחה
במערכת שלך בימות המשיח, יוצרים שלוחה (למשל שלוחה 1, או השלוחה הראשית) ומגדירים בהגדרות השלוחה (ext.ini):

```
type=api
api_link=https://kef-click-backend.onrender.com/api/yemot/call
api_add_0=key=<הערך של YEMOT_SECRET מ-Render>
```

החליפי את הכתובת בכתובת השרת שלך ב־Render, ואת `<...>` בערך של `YEMOT_SECRET`.

**חשוב:** את `api_add_0=key=...` חובה להגדיר. בלי זה השרת מחזיר "forbidden", כדי שאף אחד אחר לא יוכל לשלוח תשובות בשם המשתתפים.

אם תרצי ש־ימות המשיח ישלח POST במקום GET, הוסיפי `api_url_post=yes`. השרת תומך בשתי האפשרויות.

## מה המשתתף שומע

| מצב | הודעה |
|---|---|
| התקשר בלובי | "שלום <שם>, נרשמת למשחק <שם המשחק>, המשחק יתחיל בקרוב" |
| שאלה פתוחה | "שאלה 3, להקשת תשובה הקישו 1 עד 4" |
| ענה נכון | "תשובה נכונה, 970 נקודות" |
| ענה לא נכון | "תשובה שגויה" |
| ענה בסקר | "התשובה נקלטה" |
| ענה פעמיים | "כבר עניתם על השאלה הזו" |
| ענה מאוחר | "הזמן לשאלה הזו הסתיים" |
| מושהה | "המשחק מושהה כרגע" |
| סיום | "המשחק הסתיים, צברתם 1850 נקודות, מקום 2" ואז ניתוק |
| טלפון לא רשום | "המספר שלך אינו רשום למשחק פעיל" ואז ניתוק |

## הערות
- **פורמט התשובות:** הפורמט של פקודות `read`, `id_list_message` ו־`go_to_folder=hangup` נבנה לפי התיעוד של מודול ה־API של ימות המשיח. כל הפורמט מרוכז בקובץ אחד: `src/modules/yemot/yemot.format.ts`. אם ימות המשיח ישנו משהו, מתקנים רק שם.
- **בדיקה ראשונה:** לפני משחק עם כיתה שלמה, כדאי לבדוק עם טלפון אחד. מוסיפים את הטלפון שלך כמשתתף, פותחים לובי, מתקשרים, מתחילים ועונים.
- **ההקראה:** ימות המשיח מקריא את הטקסט בקול ממוחשב (TTS). תווים כמו נקודה, פסיק, מקף ומירכאות מוסרים מהטקסט אוטומטית, כי יש להם משמעות מיוחדת בפורמט של ימות המשיח.
- **מספר חסוי:** משתתף שמתקשר ממספר חסוי לא יזוהה. צריך להתקשר ממספר גלוי.
- **מדידת הזמן:** הזמן נמדד מהרגע שהשאלה נפתחה בשרת ועד הרגע שהבקשה מימות המשיח הגיעה לשרת. העיכוב של רשת הטלפון זהה בערך לכל המשתתפים.
